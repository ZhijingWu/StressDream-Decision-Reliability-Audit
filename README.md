# StressDream — Decision-Relevant World-Model Evaluation Audit

**Zhijing Wu · Sichuan University** · [Personal website](https://zhijingwu.github.io/)

**Status:** Independent research investigation, October 2026. Independent technical investigation; unpublished. This is an **unofficial repository, not affiliated with or endorsed by CMU Intent Lab**.

## Research question

**When does failure-oriented world-model steering provide reliable action-level evaluation?**

StressDream already reports ground-truth Dubins checks, plausibility ablations, candidate-action comparisons and policy improvement [P]. This investigation asks whether failure discovery supports action ordering and regret under matched total cost. The final steering/ranking comparison has **not** been executed.

## Scope and evidence labels

The repository contains a paper/source audit, an independently validated discrete Dubins oracle, fixed-action safety-ranking diagnostics, a separately defined decision-diverse task, a released-checkpoint compatibility pilot, and independent image-readout measurements.

- **[P]** Published-paper result, attributed to its authors.
- **[C]** Static source-code observation; performance impact is unmeasured.
- **[E]** Independently executed measurement in the retained audit records.
- **[H]** Proposed research hypothesis or unexecuted design.
- **[U]** Unresolved or unverified claim.

Historical reports keep their stage-specific status: early statements that no checkpoint had been loaded were true at that stage. The [measured Gate 1A verdict](reports/scientific_feasibility_verdict.md) governs the current compatibility/readiness status. The reports' original **[A]** label denotes analytical deductions, not experimental evidence.

## Verified findings [E]

| Stage | Retained result | Scientific meaning |
|---|---|---|
| Gate 0 | 16/16 oracle tests passed; 12/16 informative test states; 106/160 action pairs separated at .005 m² | Exhaustive H=12 support: 4,096 sign strings per query, float64, t=0 included. Constant straight A0 is practically optimal; max regret ~.000176 m². Useful for ranking diagnostics, weak for state-dependent selection. |
| Gate 0B | All 64 held-out contexts retained; 43 informative; 41 meaningfully unique optima at .005 m²; all five action IDs represented | **Changes the objective** to expected squared-distance goal progress at p=.2, constrained by support safety. Mean best-constant task regret .103087 m². All 21 no-safe-candidate states remain included. |
| Gate 1A | Structural checkpoint compatibility **PASS**; 43 nominal future predictions; 32 VAE reconstruction pairs; 215 denoiser forwards | Saved heads are present and required architectures match. This does not validate probability fidelity or ranking accuracy. |
| Independent reader | Clean/VAE empirical safety-score p95 error .00738841/.00989602 m² on 16 paired validation states per domain | Both exceed the .005 m² ranking margin and .00125 m² per-action uncertainty target. Gate 0 readiness **CONDITIONAL**; Gate 0B expected progress **NO-GO at present**. |

At .005 m², "informative" means score spread greater than the margin; "meaningfully unique" additionally requires a top-versus-runner-up gap greater than the margin. Numeric ties use 1e-12. Gate 0B utility assigns -4 m² to unsafe actions; its task regret is not Gate 0 safety regret. The best constant is an optimistic hindsight comparator. A0 is safe on all 43 feasible Gate 0B contexts, so its mean progress regret is not created by unsafe penalties. See [Gate 0 vs 0B](reports/gate0b_decision_diversity.md).

## Scientific limitations

This is not a complete StressDream reproduction, a full steering/action-ranking experiment, a new algorithm or evidence of deterioration/improvement in StressDream ranking. The current reader is not accurate enough for the proposed comparison. Model-versus-readout physical trajectory error remains confounded. Checkpoint training flip probability and nominal expectation calibration remain unresolved [U]; paper p=.2 and generator p=.4 do not establish the checkpoint's training distribution [C]. Common disturbance support does not imply equal expectations. A final pilot export error left some telemetry unavailable; it was not regenerated by inference replay.

The next proposed step [H] is qualified independent readout followed by nominal/Best-of-N/steering comparisons at matched **total** cost, with aligned score/noise/sample bookkeeping. No follow-on experiment is included or automatically authorized.

## Independent CPU oracle reproduction

No checkpoint, torch, renderer, training or GPU is required. Use Python 3.13.5 and NumPy 2.1.3 to match the recorded numerical environment; other compatible environments require their own verification. From the repository root, with NumPy already installed:

```powershell
$env:OPENBLAS_NUM_THREADS='1'
$env:OMP_NUM_THREADS='1'
python -B oracle/ORACLE_UNIT_TESTS.py
python -B oracle/ORACLE_IMPLEMENTATION.py --config oracle/CONFIG.json --output-dir reproduced/gate0
```

Use a new output directory; never overwrite retained `experiments/` evidence. The original oracle, tests and config are byte-identical to their frozen originals. [Reproduction boundaries](reproducibility/README.md), [commands](reproducibility/execution_commands.md) and [environment](reproducibility/environment.md) distinguish portable commands from historical execution records. Timing and timestamp-containing files are not promised bitwise reproducible. Gate 0B includes its frozen generator, design history and retained numerical data; a turnkey portable Gate 0B orchestration driver is not supplied.

The retained numerical claims/figure inputs can be checked without a model using `python -B reproducibility/verify_retained_results.py`. This aggregates saved CSV/JSON only. Gate 1A generation/compatibility measurements require the exact upstream assets and matching environment; weights, upstream source tree and machine-specific neural execution wrappers are deliberately excluded.
