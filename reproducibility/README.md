# Reproduction scope and integrity

This public release contains selected retained evidence, not the entire local execution archive. Original frozen records were preserved. Public report copies carry archival banners and redact machine paths; JSON metadata with local paths is sanitized. They are not claimed byte-identical. `evidence_manifest.json` distinguishes original hashes from public hashes and includes relative source locators only.

Gate 0's oracle, tests, config and numerical CSVs are byte-identical. Its exact independent CPU commands are in `execution_commands.md`. A fresh reproduction writes outside `experiments/`; all 24 grid contexts (eight calibration, sixteen test) remain in the config. H16 fallback was not triggered or executed for Gate 0.

Gate 0B publishes final V3 and earlier pre-test specifications, design amendment and seed correction, design contexts/results/summaries, and all held-out contexts/action scores/pairs/witnesses. V3 is authoritative. Seed 202610299 is separate from design seeds 202610210/202610211. The original machine-specific orchestration/source-preservation scripts are omitted; the publication supplies the generator equations, frozen controls, probabilities, tolerances and raw results, rather than claiming a turnkey portable regeneration script. Use the original oracle primitives and the declared specification for an independently implemented replay in a fresh directory. Hashes referring to omitted orchestration scripts remain historical provenance anchors, not public executable dependencies.

Gate 1A publishes saved summaries, contexts, reader parameters/code, per-image scores, nominal trajectory records, timings, tensor names/shapes and compatibility metadata. It does not bundle checkpoints, model code, neural execution wrappers, latent/noise/RGB tensor archives or the full image archive. Checkpoint origins/bytes/hashes are in `../experiments/gate1a/checkpoint_origins.json`. Any new loading or generation requires assessment of upstream provenance, restricted deserialization and a separate execution decision. The publication process did not download weights or run inference.

Early report references to omitted scripts, media or local preservation archives identify historical artifacts, not files promised in this selected release. No missing artifact is invented. Original report/config hashes and published hashes are distinct in the evidence manifest. Numerical data are preserved; path redaction does not change scientific values. Timestamps, platform strings, elapsed times and sanitized-file bytes prevent a blanket bitwise reproducibility promise.

`verify_retained_results.py` uses only the Python standard library to check selected CSV/JSON findings and public hashes. It performs no dynamics simulation, image reconstruction or learned-model inference. The release does not replace any original gate verdict.
