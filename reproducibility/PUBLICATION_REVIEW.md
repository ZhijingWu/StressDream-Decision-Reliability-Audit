# Publication review

Reviewed the entire explicit public allowlist before repository creation and again before commit. The selected release contains independent code, configs, small numerical CSV/JSON evidence, original note figures, sanitized reports and provenance hashes. No original source checkout or frozen experiment asset was modified.

Checks: file inventory; all files below 5 MiB; no checkpoint/model weights, HDF5, large dataset, credential/session file, email message or copied upstream tree; no local absolute machine paths/user identifiers in public text, JSON, PDF text or metadata; no credential/private-key patterns; Python AST/JSON/CSV parse checks; original/upstream MIT attribution retained; scientific claim-to-evidence ledger; raw figure values checked against retained per-image records. Credential detection is a pattern scan plus inspection, not a mathematical proof about every possible secret encoding.

The public PDF is an original technical note and its figures are original. Third-party paper/source are linked, with the MIT notice retained for source references/excerpts. Upstream weights, datasets and paper figures are not relicensed or redistributed.

Reports with archival banners and redacted local paths are not byte-identical originals. Manifest entries retain both original-source and public hashes. Byte-identical config/code/CSV files are labeled as such. Historical reports can refer to omitted local scripts/media; these omissions and the current Gate 1A status are documented in the reproduction guide. Public generation commands are turnkey only for Gate 0's independent oracle.

No new dynamics experiment, unit-test rerun, checkpoint load, model inference, training, steering or outreach was performed for publication. The verification script only aggregates retained values and checks hashes. Scientific limitations remain: weak Gate 0 decision diversity, changed Gate 0B objective, insufficient pixel readout precision, confounded trajectory errors, missing telemetry and undocumented checkpoint flip probability.
